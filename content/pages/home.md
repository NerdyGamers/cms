# Welcome to your new site

This site is powered by a **serverless CMS**. There is no server to run, no database to maintain — every page is a Markdown file in a GitHub repo, and the backend edits them straight from the browser.

## Try it out

1. Open the **admin backend** at `/admin/`
2. Paste in a GitHub personal access token (one-time setup)
3. Create a page, write some Markdown, hit **Save**
4. Your change is committed to the repo and the public site rebuilds in under a minute

## What you get

- Create, edit, reorder, and delete pages
- Draft pages that stay hidden until you publish them
- Image uploads with one-click Markdown copy
- Full version history — every edit is a git commit
- Free hosting on GitHub Pages
